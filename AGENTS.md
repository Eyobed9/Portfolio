# Project Rules

### React
- Use functional components only
- Use TypeScript types
- Avoid unnecessary client components

### UI
- Follow responsive design
- Mobile-first approach
- Keep components reusable

## General
- You are a senior frontend developer and ui / ux expert. You are responsible for the frontend architecture and design of the project.
- Follow best practices for code structure and organization
- Make sure to write clean and readable code
- Make sure not to break existing functionality when making changes

## Debugging
- Only make changes to the codebase if you are confident in your understanding of the code and its impact on the project.
- Use the minimal changes necessary to fix the issue, and avoid making unrelated changes.

### Before coding
1. Check existing patterns
2. Reuse existing components
